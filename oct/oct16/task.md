# Առաջադրանքներ

## Խնդիր 1. Պատահական գաղտնաբառեր

Գրել `char *generate_password(int length)` ֆունկցիան, որը `malloc()`-ով հատկացնում է `length + 1` բայթ, լրացնում է այն պատահական սիմվոլներով (մեծատառեր, փոքրատառեր և թվանշաններ) և վերադարձնում ստացված տողը։

`main`-ում օգտվողից ստանալ գաղտնաբառի երկարությունը և գաղտնաբառերի քանակը, գեներացնել և տպել այդքան գաղտնաբառ՝ յուրաքանչյուրը տպելուց հետո ազատելով նրա հիշողությունը։

**Հուշում՝** `const char chars[] = "ABC...Zabc...z0123456789";` ապա `chars[rand() % strlen(chars)]`

**Ելք՝**

```text
Երկարություն՝ 10
Քանակ՝ 3
k3TzP9aQm1
Xb7Lq2Wd0R
m8Nf4KsY2t
```

## Խնդիր 2. Դրական և բացասական

Գրել `void split_sign(const int *arr, int n, int **pos, int *pos_n, int **neg, int *neg_n)` ֆունկցիան, որը `arr` զանգվածի դրական թվերը տեղադրում է մի նոր դինամիկ զանգվածում, իսկ բացասականները՝ մեկ այլ զանգվածում (0-ները բաց թողնել)։ Նոր զանգվածների չափերը պետք է լինեն ճշգրիտ. նախ հաշվել քանակները, հետո հատկացնել հիշողություն։ Արդյունքները վերադարձնել `int **` ցուցիչների միջոցով։

**Մուտք՝** `[4, -2, 0, 7, -9, 3, 0, -1]`

**Ելք՝**

```text
Դրական (3)՝ 4 7 3
Բացասական (3)՝ -2 -9 -1
```

> **Հարց՝** ինչու՞ է `pos` պարամետրը `int **` տիպի, և ոչ թե `int *`։

## Խնդիր 3. Python-ի `range()` ֆունկցիան C-ում

Python-ում `range(start, stop, step)` ֆունկցիան տալիս է `start`-ից մինչև `stop` (առանց `stop`-ի) թվերը՝ `step` քայլով։ Գրել `int *range(int start, int stop, int step, int *size)` ֆունկցիան, որը նախ հաշվում է, թե քանի թիվ կլինի արդյունքում, `malloc()`-ով հատկացնում է ճիշտ այդքան հիշողություն, լրացնում է այն և վերադարձնում։ Քայլը կարող է լինել նաև բացասական։ Եթե `step == 0` է կամ արդյունքում թվեր չկան, վերադարձնել `NULL`, իսկ `size`-ը դարձնել 0։

**Օրինակներ՝**

```text
range(0, 10, 2)  → 0 2 4 6 8
range(10, 0, -3) → 10 7 4 1
range(5, 1, 1)   → (դատարկ)
```

## Խնդիր 4. Դինամիկ ստեկ և փակագծերի ստուգում

Սահմանել.

```c
struct Stack { char *data; int size; int capacity; };
```

Իրականացնել հետևյալ ֆունկցիաները՝

- `void stack_init(struct Stack *s)` — `capacity = 2`, հիշողությունը հատկացնել `malloc()`-ով,
- `void push(struct Stack *s, char c)` — եթե ստեկը լցված է, `realloc()`-ով կրկնապատկել `capacity`-ն,
- `char pop(struct Stack *s)`,
- `int is_empty(const struct Stack *s)`,
- `void stack_free(struct Stack *s)`։

Ստեկի օգնությամբ գրել `int is_balanced(const char *expr)` ֆունկցիան, որը ստուգում է՝ արդյոք արտահայտության մեջ `()`, `[]` և `{}` փակագծերը ճիշտ են դասավորված։ Արտահայտությունը մուտքագրել `fgets()`-ով։

**Օրինակներ՝**

| Արտահայտություն        | Արդյունք |
| ---------------------- | -------- |
| `{[()()]}`             | Ճիշտ է   |
| `([)]`                 | Սխալ է   |
| `((()`                 | Սխալ է   |
| `a[i] = (b + c) * {d}` | Ճիշտ է   |

## Խնդիր 5. Եզակի տարրեր (`realloc`-ով փոքրացում)

Գրել `int *unique(const int *arr, int n, int *new_n)` ֆունկցիան, որը վերադարձնում է նոր դինամիկ զանգված՝ `arr`-ի տարրերով առանց կրկնությունների (պահպանելով առաջին հանդիպման հերթականությունը)։ Սկզբում հատկացնել `n` տարրի համար հիշողություն (վատագույն դեպքը), իսկ վերջում `realloc()`-ով փոքրացնել այն մինչև եզակի տարրերի ճշգրիտ քանակը։

**Մուտք՝** `[4, 2, 4, 7, 2, 2, 9, 7]`

**Ելք՝**

```text
Եզակի տարրեր (4)՝ 4 2 7 9
```

> **Հարց՝** ինչու՞ է օգտակար `realloc()`-ով զանգվածը փոքրացնելը, եթե ծրագիրը առանց դրա էլ ճիշտ է աշխատում։

## Խնդիր 6. Ֆայլը ամբողջությամբ հիշողության մեջ

Գրել `char *load_file(const char *filename, int *size)` ֆունկցիան, որը կարդում է ամբողջ ֆայլը մեկ դինամիկ բուֆերի մեջ՝ առանց նախապես իմանալու դրա չափը (`fseek()`/`ftell()` և `lseek()` օգտագործել չի թույլատրվում)։ Սկզբում հատկացնել 16 բայթ, `fread()`-ով կարդալ մաս-մաս, և երբ բուֆերը լցվում է, `realloc()`-ով կրկնապատկել այն։ Վերջում ավելացնել `'\0'` սիմվոլը։

`main`-ում ֆունկցիայի օգնությամբ բեռնել որևէ տեքստային ֆայլ և տպել ֆայլի չափը, տողերի քանակը, ինչպես նաև ամենաերկար տողի համարը և երկարությունը։ Ազատել հիշողությունը։

**Ելք՝**

```text
Ֆայլի չափը՝ 1534 բայթ
Տողեր՝ 42
Ամենաերկար տողը՝ 17-րդը (88 սիմվոլ)
```

## Խնդիր 7. Բազմանդամներ

Բազմանդամը կարելի է պահել գործակիցների զանգվածի տեսքով, որտեղ `p[i]`-ն `x^i`-ի գործակիցն է։ Օրինակ՝ `3x^2 + 2x + 1` → `{1, 2, 3}`։

Իրականացնել հետևյալ ֆունկցիաները՝

- `int *poly_read(int *degree)` — օգտվողից ստանում է աստիճանը և գործակիցները, վերադարձնում դինամիկ զանգված,
- `int *poly_add(const int *a, int da, const int *b, int db, int *dres)` — երկու բազմանդամների գումարը,
- `int *poly_mul(const int *a, int da, const int *b, int db, int *dres)` — երկու բազմանդամների արտադրյալը (արդյունքի աստիճանը `da + db` է, զանգվածը ստեղծել `calloc()`-ով),
- `void poly_print(const int *p, int degree)` — տպում է բազմանդամը սովորական տեսքով։

**Օրինակ՝**

```text
p(x) = 2x + 1
q(x) = x^2 - 1
p + q = x^2 + 2x
p * q = 2x^3 + x^2 - 2x - 1
```

## Խնդիր 8. Մեծ թվերի գումար

`long long` տիպը կարող է պահել մինչև 19 նիշանոց թվեր։ Ավելի մեծ թվերի հետ աշխատելու համար դրանք կարելի է պահել տողերի տեսքով։ Գրել `char *big_add(const char *a, const char *b)` ֆունկցիան, որը ստանում է երկու ոչ բացասական ամբողջ թիվ՝ տողերի տեսքով, և վերադարձնում է դրանց գումարը՝ որպես նոր դինամիկ տող։

Արդյունքի համար հատկացնել `max(len_a, len_b) + 2` բայթ (մեկ բայթը՝ հնարավոր փոխանցման, մեկը՝ `'\0'`-ի համար)։ Գումարել թվանշաններն աջից ձախ՝ ինչպես սյունակով գումարելիս։ Եթե արդյունքի սկզբում ավելորդ 0 է մնացել, հեռացնել այն։

**Օրինակներ՝**

```text
99999999999999999999 + 1 = 100000000000000000000
123456789123456789123456789 + 987654321987654321987654321 = 1111111111111111111111111110
```

## Խնդիր 9. Գրադարան

Սահմանել.

```c
struct Book { char *title; int year; };
```

`title`-ի համար հիշողությունը հատկացնել ճիշտ ըստ վերնագրի երկարության։ Գրքերը պահել դինամիկ զանգվածում (`struct Book *books`), որը մեծանում և փոքրանում է `realloc()`-ով։

**Մենյու՝**

```text
1 — Ավելացնել գիրք
2 — Ջնջել գիրք ըստ համարի
3 — Ցույց տալ բոլոր գրքերը
4 — Գտնել ամենահին գիրքը
0 — Ելք
```

Ջնջելիս ազատել ջնջվող գրքի `title`-ը, հաջորդ գրքերը տեղաշարժել մեկ դիրք դեպի ձախ և `realloc()`-ով փոքրացնել զանգվածը։ Ելքի ժամանակ ազատել բոլոր `title`-ները, ապա ամբողջ զանգվածը։

**Հուշում՝** վերնագիրը կարող է պարունակել բացատներ, ուստի այն կարդալ `fgets()`-ով։

## Խնդիր 10. «Կյանք» խաղը (Game of Life)

Conway-ի «Կյանք» խաղում R×C չափի դաշտի յուրաքանչյուր վանդակ կամ կենդանի է (`'#'`), կամ մեռած (`'.'`)։ Յուրաքանչյուր հաջորդ սերունդ որոշվում է հետևյալ կանոններով (հարևաններ են համարվում շրջապատող 8 վանդակները).

- կենդանի վանդակը, որն ունի 2 կամ 3 կենդանի հարևան, մնում է կենդանի, հակառակ դեպքում՝ մեռնում է,
- մեռած վանդակը, որն ունի ճիշտ 3 կենդանի հարևան, կենդանանում է։

Գրել ծրագիր, որը.

- օգտվողից ստանում է `R`, `C` և սերունդների քանակը `G`,
- `char **create_grid(int rows, int cols)` ֆունկցիայով (`calloc()`-ի օգնությամբ) ստեղծում է երկու դաշտ՝ ընթացիկ (`current`) և հաջորդ (`next`),
- ընթացիկ դաշտում տեղադրում է «glider» պատկերը.

  ```text
  .#.
  ..#
  ###
  ```

- `G` անգամ հաշվում է հաջորդ սերունդը `next` դաշտում, տպում է այն, ապա `current` և `next` ցուցիչները փոխում է տեղերով (առանց տվյալները պատճենելու),
- վերջում ազատում է երկու դաշտերը `void free_grid(char **grid, int rows)` ֆունկցիայով։

**Հուշում՝** սերունդների միջև կարելի է կանչել `usleep(200000)`, որպեսզի տեսնեք «անիմացիան»։

> **Հարց՝** ինչու՞ չի կարելի հաշվել նոր սերունդը անմիջապես նույն դաշտում։
